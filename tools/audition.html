STICK DOOSH — audio audition

How this works. Every music track and SFX below has several AI candidates (Stable Audio 3 Medium via local ComfyUI). The one marked DEFAULT is what the game currently ships in assets/music/ / assets/sfx/. Candidates were picked by objective checks only (no silence, loudness, guitar-band energy, onset at start) — nobody has listened to them yet.

To swap one in: click copy promote cmd next to the candidate you like and run it from the project folder, e.g.
"C:\Users\nicho\Documents\ComfyUI\.venv\Scripts\python.exe" tools/comfy_audio/promote.py title B
It re-masters that candidate from its raw WAV (music: loop cut, -14 LUFS, 112 kbps stereo; SFX: trim, -1 dBFS peak, 96 kbps mono), overwrites the game file, records the pick in tools/comfy_audio/choices.json (so re-runs keep it) and rebuilds this page. Reload to see it. Raw WAVs + previews live in assets/raw_audio/ (git-ignored, local only). Open this page via the dev server (http://localhost:8146/tools/audition.html) or straight from disk.
