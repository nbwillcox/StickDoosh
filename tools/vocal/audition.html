STICK DOOSH - VOCAL WEAPON SFX

README

  • Every gun/impact sound is now a human mouth: LOW male "DOOSH" (shotgun), female "pew" (pistol), average male lip-trill "brr" (MG), male breath "shhhh" (rockets), raspy "fwoosh" (flame)... plus Kokoro TTS words, hand-built mouth-noise synth and Stable Audio 3 attempts, 3-8 takes each.
  • Nothing here was judged by ear (the agent that built it cannot listen). DEFAULT = best by objective checks only (non-silent, onset at start, length window, clean, decodes, right pitch class) with a prior toward the first take. INSTALLED = what is in assets/sfx/<name>.mp3 right now. You decide by ear.
  • MG v2 (kid, not frog). The first lip-trill "brr" takes (brr*, lp*, kk1, ai*) sounded like a frog (low, periodic, tonal buzz). They are kept but now FAIL new checks (dominant energy must be 800-4000 Hz, <20% below 300 Hz, no pitch <150 Hz, 1-3 hits per shot / 9-18 hits/s in the loop). New candidates: ksyn* + kl* (synth: dry plosive bursts with spit click and a faint child-pitch "ah"), ki* + kt* (child-like Kokoro "da/ka/ta/pa"), kai* + lai* (Stable Audio 3 "little kid machine gun"). Still not judged by ear.
  • Press copy promote cmd next to a take, paste it in a terminal at the repo root: python tools/vocal/promote.py <name> <take>. It copies that take into assets/sfx, rebuilds this page and js/audiolist.js. python tools/vocal/promote.py --old <name> restores the original pre-vocal sound.
  • rapid simulates how the game retriggers a weapon (its fire rate, +/- the random pitch js/audio.js adds). loop plays loop takes seamlessly (needs http, not file://). mg cycle alternates mg, mg2..mg5 per shot.
  • Files: mono, 24 kHz, 96 kbps mp3, trimmed to onset, peak -1 dBFS, short-term loudness voices -16 / shotgun+explosions -13 / loops -19 LUFS. Regenerate everything: see the top of tools/vocal/master.py.
